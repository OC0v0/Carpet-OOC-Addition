# libs/

`fabric-carpet-1.21.11-1.4.194+v251223.jar` — Carpet Mod by gnembon (MIT license), taken from the
Carpet 1.4.194 release for Minecraft 1.21.11. It is declared as a `modCompileOnly` dependency so the
mod can compile against Carpet's extension API. It is **not** bundled into the built mod: the server
provides Carpet at runtime.
